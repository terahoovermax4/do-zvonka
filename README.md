# До звонка

Android-приложение: сколько осталось до звонка. Дизайн «Чистый».
Таймер на главном экране, в уведомлении на экране блокировки и в двух виджетах.

Расписание звонков и уроков: `app/src/main/java/ru/dozvonka/app/data/SchoolSchedule.kt`.

## Как запустить

1. Установи **Android Studio** (бесплатно, developer.android.com/studio).
2. Распакуй архив, в Android Studio: **File → Open** → выбери папку `DoZvonka`.
3. Подожди, пока внизу закончится «Gradle sync» (в первый раз скачивает много, 5–15 минут).
   Если студия предложит обновить версии (AGP / Gradle / Kotlin) — соглашайся.
4. На телефоне включи **режим разработчика** (Настройки → О телефоне → 7 раз нажать на «Номер сборки»)
   и **Отладку по USB** (Настройки → Для разработчиков).
5. Подключи телефон кабелем, выбери его вверху и нажми зелёный ▶ **Run**.

Готовый файл для друзей: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**,
APK появится в `app/build/outputs/apk/debug/`. Его можно скинуть в Telegram и установить.

## Как сделано, чтобы работало на всех телефонах

| Проблема | Что сделано |
|---|---|
| Приложение выгрузили из памяти | Цифры тикают силами системы (Chronometer), а не приложения — таймер идёт сам |
| Нужно сменить «урок → перемена» ровно на звонке | Точный будильник `setExactAndAllowWhileIdle` на каждый звонок |
| Будильник «потерялся» | Страховка WorkManager раз в 15 минут + обновление при открытии приложения |
| Перезагрузка, смена времени | Приёмник BOOT_COMPLETED / TIME_SET / TIMEZONE_CHANGED |
| Vivo/iQOO, Tecno/Infinix, Xiaomi, OPPO убивают фон | **Усиленный режим** — служба переднего плана только во время уроков (включён по умолчанию на этих марках) |
| Если всё же не проснулось | Уведомление само исчезает через 3 минуты после звонка, а не показывает минус |
| Samsung прячет «тихие» уведомления | Канал обычной важности, но без звука и вибрации |
| Android 16 | Live Update: таймер в строке состояния и развёрнутым на экране блокировки |
| Pixel с Android 16 QPR2 | Виджеты можно поставить прямо на экран блокировки |
| Кривое уведомление на какой-то прошивке | Переключатель «Простое уведомление» |

Во вкладке **Настройки** приложение само определяет марку телефона
и показывает, что включить (автозапуск, батарея, экран блокировки), с кнопками перехода.

## Что проверить на каждом телефоне

1. Открыть приложение, разрешить уведомления.
2. Вкладка «Настройки» — пройти все пункты, где написано «Нужно включить» / «Проверьте вручную».
3. Поставить виджеты (кнопки «Маленький» / «Широкий» в настройках).
4. Заблокировать экран во время «урока» — таймер должен быть виден.
5. Смахнуть приложение из недавних и подождать звонка — уведомление должно смениться на «перемену».

Для теста в любое время можно временно поменять время звонков в `SchoolSchedule.kt`
(например, сделать урок, который заканчивается через 2 минуты).

## Структура

```
data/      расписание (модели + SchoolSchedule)
core/      логика: что сейчас — урок/перемена, тексты, формат времени
notify/    уведомление (Android 8–15) и Live Update (Android 16)
sched/     будильники, перезагрузка, WorkManager, усиленный режим
widget/    виджеты 2×2 и 4×2
oem/       инструкции и переходы в настройки для Samsung, Vivo, Tecno и др.
ui/        экраны: Сегодня, Расписание, Настройки
```

Тесты логики: `app/src/test/.../ScheduleEngineTest.kt` (правый клик → Run).
